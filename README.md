# Le Mont-Saint-Michel, patrimoine mondial de l'UNESCO

Projet d'équipe, BUT Informatique 1re année, IUT de Marne-la-Vallée (2025).

Site vitrine qui fait découvrir le Mont-Saint-Michel : histoire, architecture, informations pratiques, parcours de visite et visite virtuelle.

Voir le site : [saykito.github.io/Mont-Saint-Michel](https://saykito.github.io/Mont-Saint-Michel/)

## Fonctionnalités

- Vidéo d'accueil, galerie à la une et quiz interactif
- Frise chronologique et narration de l'histoire
- Six pages d'architecture : abbatiale, cloître, réfectoire, salle des Chevaliers, cryptes, remparts
- Mode daltonien et choix de la langue (français, anglais, arabe)

## Technologies

HTML, CSS, JavaScript. Maquettes réalisées sur Figma à partir de personas.

Cette version est statique et hébergée gratuitement sur GitHub Pages.
